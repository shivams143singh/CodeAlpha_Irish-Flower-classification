# CodeAlpha_Iris-Flower-classification

This repository contains the complete source code and evaluation results for **Task 1: Iris Flower Classification** as part of the Data Science Internship at CodeAlpha.

## Project Description
The goal of this project is to train a machine learning model that can automatically classify Iris flowers into three distinct species (*Setosa*, *Versicolor*, and *Virginica*) based on their physical measurements: sepal length, sepal width, petal length, and petal width.

## Dataset Details
- **Source:** Built-in Iris dataset from Scikit-learn
- **Total Rows:** 150 rows of data
- **Features Used:** 
  1. Sepal Length (cm)
  2. Sepal Width (cm)
  3. Petal Length (cm)
  4. Petal Width (cm)

## Model & Performance
- **Machine Learning Model:** Decision Tree Classifier
- **Overall Model Accuracy:** 100.00%

### Detailed Classification Report:
- **Setosa:** 100% Precision, Recall, and F1-Score
- **Versicolor:** 100% Precision, Recall, and F1-Score
- **Virginica:** 100% Precision, Recall, and F1-Score
